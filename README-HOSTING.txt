FINGER CHOOSER — PWA PACKAGE (version 2)

Files to upload to the ROOT of your GitHub Pages repository:
index.html
script.js
style.css
manifest.webmanifest
service-worker.js
icons/ (folder containing icon-192.png and icon-512.png)

IMPORTANT:
- Upload the CONTENTS of this folder, not the ZIP itself.
- Keep index.html at repository root.
- Publish via GitHub Pages over HTTPS.
- Open the published URL in Safari while online first. Add to Home Screen.
- Then test offline. On iPad, installation is a Home Screen web app, not a native App Store app.
